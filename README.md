# Copylight

Copylight is a calm, local-first clipboard manager for Windows. Search copied text and images, preview and edit clips, pin what matters, organize items into groups, and transform JSON without leaving the clipboard workflow.

- No account required
- Local-first clipboard history
- Text and image search
- Preview, text editing, pinning, groups, and bulk actions
- JSON formatting, minifying, key sorting, and stringifying
